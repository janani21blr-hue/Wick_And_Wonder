# Wick & Wonder 🧪💜

**A little magic in every sip.**

Wick & Wonder is a fictional futuristic potion café website featuring an immersive visual experience, interactive potion mixing and a demo-only shopping journey.

## 🌐 Live Demo

[Visit Wick & Wonder](https://comet-cameo-42709820.figma.site)
On netlify: https://wick-and-wonder.netlify.app

## ✨ Features

- **Immersive Homepage:** Dark, futuristic purple aesthetic with magical potion artwork.
- **Potion Collection:** Four uniquely designed potions with individual visual identities.
- **Interactive Mixing Lab:** Combine two ingredients to discover six unique potion combinations, each with its own colour palette and animation.
- **Shopping Bag:** Add products, modify quantities, remove items and calculate totals.
- **Demo Checkout:** Customer details, simulated payment methods, success and failure states, and order confirmation.
- **Responsive Design:** Layouts designed for desktop and mobile screens.

## 🛠️ Technology

- TypeScript / TSX
- CSS

- pnpm
- Figma Make

## 🧪 Demo Checkout Notice

This project uses a fictional shopping and payment experience for demonstration purposes.

No real transactions are processed, no actual orders are fulfilled, and customer details are not transmitted or persisted.

## 🧩 Project Purpose

Wick & Wonder was created as an experimental AI-assisted web development project to explore frontend implementation, interactive UI design, responsive layouts and AI-powered development workflows.
